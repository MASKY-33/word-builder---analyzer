# Word List Analyzer
This program allows the user to enter words one by one until they type "STOP".  
After collecting the words, the program performs several analyses, such as finding the longest and shortest word, counting the total words, converting words to uppercase, and reversing each word.

## Features
- Lets the user enter words until "STOP" is typed
- Stores all entered words in a list
- Finds and prints the longest and shortest word
- Counts the total number of words
- Prints the first and last word
- Converts all words to uppercase
- Reverses each word (two methods shown)

## How to use
Run the program and enter any words you like.  
Type **STOP** when you are finished.  
The program will then display all analysis results.
